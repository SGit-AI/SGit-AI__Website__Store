# ledger · V4

The local ledger is a source-linked subset, not a fabricated copy of the live 52-claim ledger. Every claim chip resolves to a state or claim entry. Entries link back to a screen and to supplied JSON. Ten states differ by label, border treatment and tone; only exists is solid navy.

## Validation boundary

Plain HTML/CSS/JavaScript; no build required. Static checks cover local routes, form prohibition, manifest coverage, source data and script syntax. Browser visual QA is not claimed.
