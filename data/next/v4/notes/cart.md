# cart · V4

The cart is browser-local and button-only. Add and remove deduplicate one policy × level; changing level updates the existing line. Order reference is generated locally, copyable, and not a real provider reference. Load-example controls are visibly design controls. A 100% applied-code state uses [CODE] and amounts computed from source prices; no actual discount code is exposed. No account or cookie is introduced.

## Validation boundary

Plain HTML/CSS/JavaScript; no build required. Static checks cover local routes, form prohibition, manifest coverage, source data and script syntax. Browser visual QA is not claimed.
