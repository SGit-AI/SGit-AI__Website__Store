# picker · V4

Search has hardware-key support and a button keyboard to obey the no-form rule. Categories, state filters, grid/list, linked selection and all 23 behaviour options are interactive. Policy state uses measured only where the supplied summary says measured; others are read, not run. A derived state specimen is labelled as a specimen, not assigned as a fact. Missing scope/tool fields and capability-to-policy joins cannot be searched as factual matches: a capability selection reports the missing mapping instead of returning invented results. Normal use uses published aggregates; Advanced marks scenario-dependent counts unknown while preserving grant. Per-cell classification, dates, side-effects, scenario count and trifecta evidence are placeholders. A/B/C place the till after evidence/in header/in dock respectively. Product links preserve policy selection.

## Validation boundary

Plain HTML/CSS/JavaScript; no build required. Static checks cover local routes, form prohibition, manifest coverage, source data and script syntax. Browser visual QA is not claimed.
