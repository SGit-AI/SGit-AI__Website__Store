The queue, and how work gets here

The memo queue → — a memo from the project lead arrives spoken, is kept here word for word, is read into a brief, and the brief is broken into units of work. The reading is kept separate from the memo on purpose: what somebody said and what we made of it are two different objects, and only one of them is allowed to be wrong.

The board → — those units, in four columns, grouped into workstreams. A workstream never moves by hand; it moves because a task inside it moved, so the summary cannot contradict the detail.

4 more codes exist and are not on this page. They ship as a SHA-256 and never as a string, so they are not in the built site, not in the markdown twins and not in this console — a check reads every byte of the output against every code on every release. Read them out of data/discounts.yml, which is in the repository and not in the site.

Opening one of these lands on the shop with the discount already applied and the four prices repainted, and the code is taken out of the address before the page settles — so it is not in history, not in a bookmark and not in a referrer. Any page here takes ?code=, not just the front one.

StripeThe rail that turns a buyer into a customer, including a buyer who pays nothing. Six products, eight prices, three coupons — and a webhook that has to listen to the session rather than the payment, because a hundred-per-cent order creates no charge at all.
SumUp — parkedTaken off the store on 16 September for the first end-to-end MVP. The plan is kept rather than deleted, so turning it back on is restoring a record instead of rediscovering an argument.

Run it yourself

The walkthrough → — a beta tester or an agent goes from the catalogue to the page after payment in about four minutes, for nothing, with a discount code printed on the page. Screenshots of every step, and a script an agent can follow without a person in the loop.

The same thing as PDFs, for sharing or for reading away from a screen — by hand (11 pages, every screenshot) and as an agent (7 pages, the assertions). Both are snapshots; the page is the source of truth.
