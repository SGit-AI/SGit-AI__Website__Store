/ work / board-readable

The version the board can read

0 of 5 units done. “Can I have this in a form my board can read?” Every vault should already contain one — the policy re-cut for the people who have to sign it off. Not a paid extra and not an add-on: every vault, including the ones anybody can download for nothing.

This workstream came out of a memo. Five audiences, decoupled views, and the version the board can read, 2026-09-16 — kept verbatim, read into a brief, and broken into the units below.

Queued2

BR-4Put it in the free vaults first

“Including the ones you can download for free.” Doing the free ones first is the harder order and the right one: it proves the cut is generated rather than hand-finished for a paying customer.

Blocked on BR-1, BR-2.memo 2026-09-16
BR-5Re-read the entry level once it carries one

A £10 pack that contains a version the board can read is a different argument from a £10 pack that does not. It also earns a row on the comparison table, which is where the difference between the levels is now legible — and it is kept off that table until it exists.

Blocked on BR-4, PL-2.memo 2026-09-16

BR-1Specify what a board-readable cut actually is

Length, what it leads with, what it leaves out, and what a reader is expected to do with it. It is the whole deliverable, so specifying it badly is worse than not shipping it.

Fifteen shapes. Generated, written once per shape, or written per sale — the answer changes what the entry level costs to fulfil and therefore whether £10 is the right number.
