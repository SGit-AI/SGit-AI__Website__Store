The comparison table

4 of 6 units done. Features down the left, five columns across — free, £10, £50, £500, £1,500. The page that makes the differences between the levels legible, and the one that finally explains the entry price, because a licence is only a difference next to a column that does not have it.

This workstream came out of a memo. One table, five columns, and the free one first, 2026-09-16 — kept verbatim, read into a brief, and broken into the units below.
