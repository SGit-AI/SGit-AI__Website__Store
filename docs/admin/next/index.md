# /next/ — the next store

The v3 design direction **01 / ABP first**, built here. It runs beside the store that sells today rather than replacing it.


## Nothing on /next/ can be bought

No payment link has been issued on any level, so every buying action renders as a disabled control carrying its reason.


## One section of the design is not built

The v3 pages carry a mission line that uses a word this site bars absolutely, on every page, with no allowlist and no carve-out for a quotation. Their own notes record that the project lead asked for it. The section is left out, the mirror keeps their file intact, and the ruling is on the board.
