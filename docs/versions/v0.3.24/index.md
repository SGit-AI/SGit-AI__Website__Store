# v0.3.24 — the emails nobody has turned on, and the one a free order cannot send

Neither side is emailed on a sale today. The buyer's receipt is a dashboard
setting rather than a property of the payment, and the seller's notification is
a per-person preference on the account; both are steps on the rail page now.

The half worth reading twice is that neither fires on a zero-total order. A
hundred-per-cent code takes the total to zero, a zero total creates no charge,
and both of those emails hang off a charge — so the exact journey this rail was
built for, handing somebody a code at an event and ending up with a person in a
system, is the journey that notifies nobody by any route. It is on the board as
an argument rather than a setting.
