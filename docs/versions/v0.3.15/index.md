# v0.3.15 — the rest of the next store: the comparison, the doors, the ledger and the person

Four more pages at /next/, each rendered from the file the current store is
already rendered from: what arrives at every level, who this is for, the claim
ledger, and who does the work at the two levels a person does.

**The ledger is here so a claim chip stops throwing the reader out of the
round.** Every chip on every /next/ page now lands on a row in this design.
It is the same 52 claims from the same file — there is no second copy — and it
prints which pages say each one.

The fifth screen in the pack, the generic template, is deliberately not a page:
it is a reading column already exercised by the ledger and the reviewer page,
and re-rendering an existing content page at a second URL to demonstrate it
would put the same paragraphs in two places on one site.

**A claim now registers the URL of the page that says it, not that page's
internal label.** Several generated pages carry a label that does not match
their route — /admin/reviews/ registers "reviews" — and resolving one from the
other produced ten dead links on the ledger's first build.

Ten deliberate breaks across the two new checks, each naming its own thing: a
comparison row, a row group, the free column's position, an audience lens
without a panel, a lens that hides something, the ledger as a selection, a
truncated reviewer name, a dropped source, and a round number of years the
reviewer file says at length must never be published.

Also: `img { max-width: 100% }` in the reset silently won the cascade against
`width: 500%`, so four of the five audience cards showed an empty box with the
artwork pushed off it.
