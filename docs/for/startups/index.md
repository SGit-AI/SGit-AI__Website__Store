# You are a startup, and diligence is coming

A founder who will be asked these questions by somebody else, and would rather see the answers first.

You arrive asking: “What is diligence going to find before it finds it?”

**Nothing on the offer list was built pointing this way.** Everything below was built for one of the other two buyers and is run in the opposite direction. There is no seventh product behind this page.

## What the market looks like here

Two funded incumbents, a free tier beneath them, and both already publish the answer. Selling a founder a posture document is selling into a commoditised tier — so that is not what is here. The unoccupied offer is the reverse one: the same components, pointed the other way.

## What you are actually buying

**The investor's review, run early, and run for you.** There is no separate product behind that sentence: you buy tier 3 or tier 4 and say which direction you want it run in.

## The offers you are shown

- `t3` — Tier 3 — £150 to £1,000 — Will somebody look at my situation with me? — A fixed-price link carries one price, and this one is a band — so the link is issued once the band is fixed for the case.
- `t4` — Tier 4 — £5,000 to £10,000 — What would a team of security professionals find? — Above about £1,000 a card stops making sense, so this one goes by invoice and bank transfer after a conversation.
- `t2` — Tier 2 — £50 to £100 — Which parts of the regulation actually reach me? — A fixed-price link carries one price, and this one is a band — so the link is issued once the band is fixed for the case.
- `add-formats` — Add-on — By depth band — Can I have the same result in a form the board will read? — This attaches to another offer and is priced against its depth band, so it has no checkout of its own.

## What you are not buying

- A distinct offer. The reverse direction is a framing of tiers 3 and 4, not a seventh thing on the price list, and this site does not pretend otherwise. {{claim:startup-offer-is-reverse-only}}
- A posture document. That tier is already free from two funded incumbents, and buying one here would be paying for something published.
- A guarantee about what a particular investor will ask. What is run is the review; which questions a given firm asks is theirs.
