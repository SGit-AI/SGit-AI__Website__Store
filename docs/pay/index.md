# Checkout

One button per line of your order, because one payment link sells one line. Each opens the provider's own page.

## The hand-off

- **What the provider asks for:** name, email address, card details, on its own page and under its own terms.
- **What this store sends:** an order reference, and the discount code when you arrived with one. Not the amount — that is the provider's, on the provider's own product.
- **What comes back:** the provider's own session identifier, if their page is set to return one. Not a confirmation. There is no server here to ask whether the payment cleared, so this store never says that it did.
- **What this store receives:** nothing. There is no form, no input and no field anywhere in this site's output, no network request from any page that sells anything, and no server to receive one.
