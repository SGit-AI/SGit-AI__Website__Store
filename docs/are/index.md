# Who you are

Five ways in, over the same four things. Nothing is hidden from anybody; what changes is which level a view opens on.

- **You are a founder** — We are shipping with agents and somebody is going to ask what they can reach. — https://store.sgit.ai/are/founder/
- **You are backing a company** — I need somebody to look at what this company's agents can actually do, and I need it to be somebody's work. — https://store.sgit.ai/are/investor/
- **You have to answer for it** — Can I have this in a form my board can read? — https://store.sgit.ai/are/exec/
- **You do this for a living** — I can write the policy. What I want is the structure and the vocabulary, and I want to see how you compute the delta. — https://store.sgit.ai/are/security/
- **You own the register** — Where does this sit against the frameworks we already report on? — https://store.sgit.ai/are/governance/
